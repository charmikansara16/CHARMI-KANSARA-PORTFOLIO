## 🌐 GitHub Pages Deployment Guide

To enable live public hosting on GitHub Pages for your professor to open directly:

1. Open your repository on GitHub: [https://github.com/charmikansara16/CHARMI-KANSARA-PORTFOLIO](https://github.com/charmikansara16/CHARMI-KANSARA-PORTFOLIO)
2. Click on **Settings** tab (top menu).
3. Scroll down to the **Pages** section on the left sidebar under *Code and automation*.
4. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`.
   - **Branch**: Select `main` branch and `/ (root)` folder.
5. Click **Save**.
6. GitHub will automatically deploy your site in 1-2 minutes at:
   `https://charmikansara16.github.io/CHARMI-KANSARA-PORTFOLIO/`
